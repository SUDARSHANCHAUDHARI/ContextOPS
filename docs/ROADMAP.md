# Roadmap

## Phase 1

- Tool detection.
- Defensive local scanning.
- Session parsing.
- Token and cost estimation.
- SQLite persistence.
- CLI summaries.
- Replay timelines.
- Waste pattern detection.
- Local dashboard scaffold.

## Phase 2

- Tool-specific parser fixtures for all initial adapters.
- Replay viewer with frame navigation, metrics, evidence, and root-cause context.
- Project rollups.
- Model switching analytics.
- Budget alerts.
- TUI interaction with tabbed navigation and selected-row detail.

## Phase 3

- VS Code extension.
- Live IDE overlays.
- Prompt optimization engine.
- Team analytics.
- Optional cloud sync.
- Enterprise controls.
- Workflow graph visualization.
- Agent tracing and anomaly detection.
